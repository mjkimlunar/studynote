# 스타일 예시 폴더

이 폴더에 본인이 직접 쓴(=AI 도움 없이 쓴) 짧은 글 2~5개를 `.txt` 파일로 넣으세요.
파일명은 자유 (예: `01.txt`, `02.txt`).

**주의**
- 이 폴더의 `.txt` 파일은 `.gitignore`로 제외되어 있어 공개 저장소에 올라가지 않습니다 —
  사적인 글이라 안전합니다.
- PRD §3.2에서 정리한 기준대로: **AI와 합작한 글은 넣지 마세요.** 순수 본인 문체 글만.
- 기존 블로그 글이 없다면, 지금 짧게 2~3개 새로 써서 넣어도 됩니다 (PRD §2 "경로 B").
